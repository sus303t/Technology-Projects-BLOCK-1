# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
 --> Hardware is the physical part of computer which can be seen or touch. It is also the tangible parts that execute 
instructions and process data.Core Internal Hardware are CPU, Motherboard,Random-Access Memory(RAM), Storage Devices,
Graphics Processing Unit(GPU).

## Explain Software
Write **at least 50 words** explaining what software is.
---> Software is the collection of programs which tells computer what to do and how to perform specific tasks.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact. 
Hardware and Software interact through a layered stack where high-level human commands are systematically 
translated down into physical electrical signals.
